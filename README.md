# 📅 Organizer Bot v3

Telegram-бот для сохранения событий с напоминаниями. Никаких внешних сервисов — только SQLite. Поддерживает свободный текст, голосовые сообщения, повторяющиеся события и экспорт в календарь.

## Структура проекта

```
bot/
├── main.py                 # Точка входа
├── config.py               # Настройки из .env
├── requirements.txt
├── .env                    # Переменные окружения (не коммитить!)
│
├── db/
│   ├── __init__.py
│   └── models.py           # SQLite: WAL-режим, миграции, все модели
│
├── handlers/
│   ├── __init__.py
│   ├── start.py            # /start, /help
│   ├── events.py           # Все обработчики событий
│   ├── keyboards.py        # Inline-клавиатуры
│   ├── natural_parser.py   # Парсинг даты из текста (dateparser)
│   └── voice.py            # Распознавание голосовых (OpenAI Whisper)
│
└── utils/
    ├── __init__.py
    ├── logger.py            # Логирование
    └── reminder.py          # Фоновый поток напоминаний
```

## Установка и запуск

```bash
pip install -r requirements.txt
pip install python-dotenv   # для загрузки .env
```

Заполните `.env` (см. раздел ниже), затем:

```bash
python main.py
```

## Переменные окружения (`.env`)

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | Токен от @BotFather (обязательно) |
| `DATABASE_PATH` | `data/events.db` | Путь к SQLite файлу |
| `REMINDER_MINUTES` | `10,30` | За сколько минут до события напоминать (через запятую) |
| `OPENAI_API_KEY` | — | Ключ OpenAI для голосовых сообщений (необязательно) |

## Команды бота

| Команда | Описание |
|---|---|
| `/start` | Приветствие и справка |
| `/help` | Справка |
| `/events` | Список ближайших событий |
| `/add <текст>` | Добавить событие с выбором повтора |
| `/search <запрос>` | Поиск по названию события |
| `/stats` | Статистика: создано / выполнено / предстоит |
| `/export` | Скачать `.ics` файл для импорта в Google/Apple/Outlook Calendar |
| `/timezone` | Сменить часовой пояс |
| `/cancel` | Отменить текущее редактирование |

## Как добавить событие

Написать текстом — команда не нужна:
```
Завтра в 15:00 Встреча с командой
В пятницу в 10:30 Звонок с клиентом
Через 2 часа Купить продукты
```

Или через команду (предложит выбор повтора):
```
/add Каждый понедельник в 9:00 Планёрка
```

Или голосовым сообщением — бот распознает речь и покажет карточку подтверждения перед сохранением.

## Кнопки под событиями

| Кнопка | Действие |
|---|---|
| ✏️ Изменить | Редактировать дату или название |
| 🗑 Удалить | Удалить с подтверждением |
| ✅ Выполнено | Отметить выполненным |

## Кнопки в напоминаниях

| Кнопка | Действие |
|---|---|
| ✅ Выполнено | Отметить событие выполненным |
| ⏰ +30 мин | Перенести событие на 30 минут вперёд |

## Повторяющиеся события

При добавлении через `/add` бот предлагает выбор:
- 🔁 Ежедневно
- 📅 Еженедельно
- 🗓 Ежемесячно
- ➖ Без повтора

После наступления времени события следующее вхождение создаётся автоматически.

## Технические детали

- **БД**: SQLite в WAL-режиме — нет блокировок при параллельных пользователях
- **Миграции**: версионирование схемы через таблицу `schema_version`, новые изменения добавляются без ручного вмешательства
- **Заблокированные пользователи**: если пользователь заблокировал бота, он помечается как неактивный и напоминания прекращаются
- **Голосовые**: используется OpenAI Whisper (`whisper-1`), ~$0.006 за минуту аудио
- **Часовой пояс**: по умолчанию `Europe/Moscow`, меняется через `/timezone`
