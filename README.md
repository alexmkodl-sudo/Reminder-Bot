# 📅 Reminder Bot

Telegram-бот для сохранения событий с напоминаниями. Никаких внешних сервисов — только SQLite.

## Структура проекта

```
bot/
├── main.py              # Точка входа
├── config.py            # Настройки
├── requirements.txt
├── .env.example
│
├── db/
│   ├── __init__.py
│   └── models.py        # SQLite: пользователи, события, напоминания
│
├── handlers/
│   ├── __init__.py
│   ├── start.py         # /start, /help
│   ├── events.py        # /events, /add, свободный текст, удаление
│   ├── keyboards.py     # Inline-клавиатуры
│   └── natural_parser.py# Парсинг даты из текста
│
└── utils/
    ├── __init__.py
    ├── logger.py        # Логирование
    └── reminder.py      # Фоновый поток напоминаний
```

## Установка и запуск

```bash
pip install -r requirements.txt

BOT_TOKEN=ваш_токен python main.py
```

Или через `.env`:
```bash
cp .env.example .env
# заполните .env
python main.py
```

## Переменные окружения

| Переменная | По умолчанию | Описание |
|---|---|---|
| `BOT_TOKEN` | — | Токен от @BotFather (обязательно) |
| `DATABASE_PATH` | `data/events.db` | Путь к SQLite файлу |
| `REMINDER_MINUTES` | `10,30` | За сколько минут напоминать |

## Как пользоваться

| Действие | Результат |
|---|---|
| `/start` | Приветствие и справка |
| `/events` | Ближайшие события |
| `/add Завтра в 15:00 Встреча` | Добавить событие |
| `Завтра в 15:00 Встреча` | То же самое без команды |
| Кнопка 🗑 под событием | Удалить с подтверждением |

Бот каждую минуту проверяет события и присылает напоминание за нужное количество минут.
